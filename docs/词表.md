# 词表

**状态**：成形。
**一句话**：这条词在本仓什么意思 —— 一个词只在这里解释一次，别处再解释一遍就是漏改。

| 词 | 一句话 |
| --- | --- |
| **单向逼近** | 扫描时每个点都从同一侧走到目标，不停在任意一侧 —— 因为台子从两个方向走近同一处会停在不同位置。 |
| **命令值** | 下发给台子的目标位置。它答的是「让它去哪」，不是「它到了哪」。 |
| **读出位置** | 台子在某一刻报回来的位置；扫描里每点存一次，是横轴的默认来源。 |
| **设备读回原值** | 台子自己那套单位报的数，没折算成 µm —— 口径只在设备边界折一次。 |
| **折算系数** | 设备读回原值 → µm 的乘数；是设备的属性，只写在后端一处。 |
| **到位** | 设备层给出的结论（到位 / 超时 / 中止）。PI 用控制器信号 + 固定延时；XMT 等满稳定延时即算。 |
| **稳定延时** | 移动之后到采图之前等的那段时间；XMT 上它是唯一的时序保证。 |
| **步距复核** | 采图前再量一次偏差、超过半个步距就判该点无效的那道校验；PI 做，XMT 不做。 |
| **软停** | 不再下发新目标，但在途行程拦不住 —— 与「急停」「释放」不是一回事。 |
| **释放** | 卸力（异常振动时用）。能做到什么程度取决于设备。 |
| **遥测** | 后台按固定节拍向设备询问一次状态与位置；曲线与界面读数都取自它。 |
| **认识账** | 每台设备一份的记账：已证实 / 未证实 / 已作废 / 经验与坑 / 对后端的处置。 |
| **处置** | 认识账里「后端该怎么做」那一条 —— 它是硬要求，不是建议。 |
| **证据强度** | 认识账里每条事实的可信度：实测 / 文档互证 / 外部资料 / 推断。 |
| **原生帧** | 相机传感器直接出来的那一帧：全幅、16 位、未旋转、未拉伸。 |
| **质心** | 整幅图的强度加权重心（不扣背景、不设阈值、不开窗），按传感器坐标报。 |
| **裁剪矩形** | 原始坐标上的 `x0,y0,w,h`；库里与 PNG 的 tEXt 各记一份，读文件时减一次偏移。 |
| **导出物** | 一次导出的产物：原始帧 + 每点元数据 + 清单；可以是一个目录，也可以是一个 zip。 |
| **名义 Nyquist** | 1/(2×平均点间距)：频谱能说清的最高频率，越界给的是混叠。 |
| **谱线密度** | 画出来的谱有多密：频率格 = 1/(密度×T)。只管画 —— 分辨率仍是 1/T，整数格上的功率一根不变。 |
| **频率分辨率** | 1/T，T 是真的观测了多久。谱线密度改变不了它，加密只是把同一条谱画得更密。 |
| **包络** | 带通信号的解析信号幅度 |z|；强度半高宽、相位门限都按它说。 |
| **相位门限** | 相对最强那根（或最强那个像素）的 dB 下限；以下的不画，因为算得出却不可复现。 |
| **傅里叶变换极限** | 同一段谱线、幅度不动、相位全拉平之后的重建曲线 —— 这条带没有色散时该有的样子。 |
| **群延迟** | 相位随频率的斜率换算成的时间：整段信号比这条序列最早那一拍晚到了多久。频谱那条相位里被减掉的直线就是它。 |
