# 设备层设计

**状态**：成形。
**一句话：这份讲设备层对外承诺什么 —— 上位只看到「到位 / 超时 / 中止」、一组能力声明和一份状态，看不到台子之间的差别。** 词在 [词表](../词表.md)；需求在上游（[需求](../需求.md)）；扫描执行器见 [扫描](扫描.md)，相机见 [相机](相机.md)；设备事实与实测数字见各设备的「认识账」。

## 这份设计认领了哪几条需求

| 需求 | 这一层给出的回答 |
| --- | --- |
| 「到位由设备层给结论」 | 一次移动只回三种结局：到位 / 超时 / 中止；判据每台自己定，上层不看 |
| 「每台设备按自己的事实实现」 | 停止、释放、行程、停稳各按自己那份事实；差别全部写进能力声明 |
| 「设备能力随状态下发」 | 状态里带能力声明，界面据它改文案；夹取与安全逻辑从不读它 |
| 「行程以实测可用区间为准」 | 行程区间由设备层给：有标定数据的用自报值，没有的用实测可用区间 |
| 「折算系数不能长期写死」 | 折算只在设备边界做一次；系数是设备属性，不往上层漏 |
| 「XMT 在设备边界折算」 | 读回值到设备层为止，绝不流进设点 |
| 「PI 停稳由控制器判」 | PI：控制器到位信号 + 一段固定延时 |
| 「XMT 不做任何到位判据」 | XMT：只等满稳定延时，到点即回「到位」 |
| 「XMT 无速度指令」 | 设速度明确拒绝并报错 |
| 「XMT 没有停止运动与关伺服」 | 停止只能软停、释放只能卸力；做到什么程度写进能力声明 |
| 「停止与释放分开」 | 两个独立动作，各自返回「实际做到了什么」 |
| 「只做闭环」 | 没有开环 / 电压模式这条通路 |
| 「位置精度是台子的属性」 | 本层只报「命令了什么」与设备自己说的「到了没」；不承诺实际走到了哪 |
| 「读数与闭环同一个传感器」 | 位置读数与闭环同源；传感器自身的标定误差不在本层 |
| 「PI 的停止与释放按设备语义」 | PI：专用停止指令与关伺服，不写成「保持伺服」 |
| 「XMT 仅 Windows」 | 平台写进能力声明，别的平台上直接拒绝 |
| 「XMT 丢帧是静默的」 | 设点有没有生效不判断；代价照实写进文档，不假装有兜底 |
| 「Linux 与 Windows 都能跑」 | PI 两条通路；XMT 与相机只在 Windows |


## 一、一台设备，一次一个

承诺：配置里选一台，同一时刻只激活一台；没被选中的那台连依赖都不加载。

出什么事会说什么：选的是 XMT 而驱动装不上 —— 连接直接报错，说清缺什么、可以改回 pi；配置里的设备名不认识 —— 当场拒绝，不猜。

## 二、能力声明

承诺：连上之后，状态里带一组能力，界面照着说话：平台、有没有硬件到位信号、有没有专用停止指令、释放能做到什么程度、设点有没有应答、能不能设速度、原生单位、稳定延时默认值、读回 → µm 的折算系数、采图前做不做步距复核。

出什么事会说什么：能力声明只改文案与可用性 —— 界面据此禁用速度框、改写停止与释放的说明；夹取与安全判断从不读它。

## 三、状态

承诺：状态给这些：连接与否、当前位置（µm）、目标、速度、伺服、到位、溢出、错误码、行程区间、轴名、序列号、型号、更新时间，以及「这个到位结论是谁给的」（控制器给的 / 后端按读数比较的 / 未记录）。

出什么事会说什么：没连上时位置停在最后已知的那个数，界面写明「未连接」；不拿旧读数冒充实时位置。

## 四、移动

承诺：移动 / 点动只接受 µm；进硬件之前夹到行程区间；返回的是「到位 / 超时 / 中止」，不返回「大概到了」。

出什么事会说什么：超出区间 → 夹到端点并照实下发，界面看到的是夹过的那个目标；等待期间被中止 → 报中止，不报到位。

## 五、停、急停、释放

承诺：三个动作分开。停止返回「硬停 / 软停 / 什么都没做」三选一，调用方据此决定提示语；急停立即执行；释放按设备能做的做（PI 关伺服、台子回弹；XMT 切开环并把输出写零，不保证停在原位）。

出什么事会说什么：软停时界面提示「不再下发新目标（在途行程拦不住）」；释放后不承诺位置不变。

## 六、行程与夹取

承诺：行程区间以设备文档里的实测可用区间为准。有标定数据的设备，自报值就是权威；没有标定数据的设备，自报值只当参考区间，用实测可用区间。

出什么事会说什么：设备报的行程越界（读错了）→ 拒绝连接并说清，不拿一个猜的区间顶上。

## 七、折算

承诺：读回值到设备层为止。对外一律 µm：`µm = 读回值 × 系数`，系数是设备属性；设点只吃 µm，读回值绝不回流成设点。

出什么事会说什么：系数被改过时，本层不诊断、不拦截（诊断的触发点已随读回确认一起删掉）；症状只剩「读数再也落不到目标附近」与界面「到位」列。

## 八、两台设备的差别（对照）

| 事 | PI E-709 | XMT E53.D1S-H |
| --- | --- | --- |
| 平台 | Windows + Linux | 仅 Windows |
| 到位 | 控制器信号 + 固定延时 | 只等满稳定延时 |
| 步距复核 | 做 | 不做 |
| 停止 | 硬停，保持伺服 | 软停：不再发新目标 + 当前位置写回 |
| 释放 | 关伺服 | 切开环 + 输出写零 |
| 速度指令 | 有 | 没有，明确拒绝 |
| 读回单位 | 就是 µm | 4/3 µm（系数 0.75） |
