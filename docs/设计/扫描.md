# 扫描设计

**状态**：成形。
**一句话：这份讲一次扫描对外承诺什么 —— 从按下「开始」到收场，每一步发生什么、出什么事说什么。** 词在 [词表](../词表.md)；需求在上游（[需求](../需求.md)）；设备层见 [设备层](设备层.md)，相机见 [相机](相机.md)，落盘与库见 [数据](数据.md)。

## 这份设计认领了哪几条需求

| 需求 | 这一层给出的回答 |
| --- | --- |
| 「一次扫描 = 逐点移动 + 每点一张图」 | 逐点做三件事：移动 → 等稳定延时 → 采图 |
| 「任务独立于浏览器」 | 执行器自己跑；关页面、断网都继续 |
| 「单向逼近」 | 先退到起点外侧再逼近；每点从同一侧过来 |
| 「PI 每点按步距复核」 | 采图前复核一次偏差，超过半个步距：不采图、不入库、中止 |
| 「XMT 不做任何到位判据」 | 设备声明不做，这一步整段跳过（含读数比较的拦截） |
| 「扫描能暂停、继续、中止」 | 三个独立动作，各自即时生效 |
| 「一台设备一个使用者」 | 扫描占着设备时，手动操作与相机接口被 409 拒 |
| 「位置只记一点」 | 每点记一次读数，随该点入库 |
| 「位置曲线不额外轮询设备」 | 扫描进行中不再自己轮询；曲线样本改用扫描读到的那次位置 |
| 「每点采图的顺序」 | 触发 → 读位置 → 取帧 |
| 「停完说得清状态」 | 收场只有三种：完成 / 中止 / 失败；跑过的点都在库里 |
| 「等待时长不是设备常量」 | 稳定延时由界面给，默认值随设备走 |
| 「点位表」 | 每点的命令值、读数、原值、稳定延时、到位、曝光、采图时刻、图的尺寸与位深都入库 |
| 「历史扫描表」 | 每条扫描一行，缺的字段留空不编 |
| 「随时能停」 | 暂停与中止在任何时刻都生效，不等一整点做完 |
| 「不需要高实时采样」 | 慢速轮询；采图那一刻读一次位置就够了 |
| 「预留联动接口」 | 每点到位的结论与图路径都在元数据里，外部设备可接在这一步之后 |
| 「PI 扫描必须单向逼近」 | 与「单向逼近」同一条路，判据不按设备分叉 |
| 「闭环控制台」 | 走位、采图、事后取数三件事都在这一条链上 |


## 一、开始之前

承诺：先校验一遍再动设备 —— 起终点在行程内、点数 ≥ 2、步距与延时在允许范围内；相机若在预览，后端自己先关预览，不等界面点。

出什么事会说什么：位置不在行程内 → 400 并说清允许区间；设备正忙 / 正在扫 → 409；相机开不起来 → 扫描不开始。

## 二、逐点的一轮

承诺：每点按这个次序做完，中间任何一步被中止就收场：

1. 算出这一点的目标（按命令值等间隔）。
2. 移动（设备层负责夹取与到位结论）。
3. 等稳定延时（期间可被暂停 / 中止打断）。
4. PI 才做的那道复核：读数与目标差超过半个步距 → 该点判无效，不采图、不入库、中止整条。
5. 采图与读位置：相机在场时先触发曝光、同时读一次位置、再取这一帧；位置读数落在这一帧的曝光窗里。
6. 这一点的元数据写库。

出什么事会说什么：复核不过 → 明确说是第几点、差了多少；相机出错 → 整条就地失败，不重试、不跳过、不清理半截扫描。

## 三、单向逼近

承诺：正式往下走之前先退到起点外侧一段距离，再朝扫描方向逼近；首点因此与其余点从同一侧过来。起点贴着行程端点、退不出去时，首点改用更长的稳定延时，并留一条警告。

出什么事会说什么：预逼近退不出去 → 记一条警告，照常扫；首点仍按加长的延时采。

## 四、暂停、继续、中止

承诺：暂停 = 停在当前点，不采新点，已采的点都在库里；继续 = 从下一个点接着走；中止 = 收场，已跑的照实留下。三个动作各自即时生效，不需要等一整点做完。

出什么事会说什么：收场时说清这次是「中止」还是「失败」，以及跑到第几点。

## 五、扫描期间的共享状态

承诺：扫描占着设备 —— 手动移动、点动、改速度、释放、相机接口一律 409；遥测降到低频，把设备带宽让给扫描；位置曲线的样本由扫描的读数接上，不额外敲设备。

出什么事会说什么：扫描进行中被点手动 → 409，提示「扫描进行中或已暂停，请先中止再手动操作」。

## 六、收场

承诺：无论怎么结束，库里的东西都说得清：每点的命令值、那一刻的读数、原值、到位、曝光、采图时刻、图的尺寸与位深；缺图的点就是没图，不补一个占位的。

出什么事会说什么：中途失败 → 这条扫描就地标记失败，半截扫描由人在界面上手动删除。
