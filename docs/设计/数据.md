# 数据设计

**状态**：成形。
**一句话：这份讲库与文件对外承诺什么 —— 一次扫描存下什么、取数时读什么、裁剪与导出导入怎么保证「一个字节都不冒充」。** 词在 [词表](../词表.md)；需求在上游（[需求](../需求.md)）；扫描怎么写进来见 [扫描](扫描.md)，界面上怎么画见 [界面](界面.md)。

## 这份设计认领了哪几条需求

| 需求 | 这一层给出的回答 |
| --- | --- |
| 「位置只记一点」 | 每点一行元数据，记一次读数 |
| 「点位表」 | 每行的字段：命令值、读数、原值、稳定延时、到位、曝光、采图时刻、图的尺寸与位深 |
| 「历史扫描表」 | 每条扫描一行；缺的字段留空 |
| 「像素取原值」 | 取数返回每点的原值，不做任何加工 |
| 「横轴默认是读数」 | 每点那一次的读出位置，µm |
| 「横轴可换时间」 | 另给一列时间（fs）：光程差 = 2×位移，除以 c；系数只在这一处 |
| 「位置轴可切口径」 | 四列一起下发：折算 / 原值 × 位置 / 时间；口径记在扫描上；老数据可指认一次 |
| 「没图的点断开」 | 没图的点就是没有值，接口不给 0、不给插值 |
| 「坐标口径不因加工改变」 | 裁剪只在读文件那一层减一次偏移 |
| 「不留半成品」 | 裁剪、导入、导出都先落暂存、校验过再就位；导入占号先于落图，失败撤号删图 |
| 「数据要能离开这个程序活着」 | 图是 PNG、元数据随行、原始帧拿得到 |
| 「导出物自己说得清」 | 一份清单 + 一张表，缺什么写明 |
| 「搬出去能原样搬回来」 | 导入照抄值，撞号就拒 |
| 「裁剪」 | 只裁选中的那一条，就地换图，越裁越小 |
| 「相位图」 | 一遍扫完全图算完，结果只在内存里 |
| 「强度对齐绘图」 | 一遍读盘只产出两张与 n 无关的图（带内交流能量、直流），n 与门限都在界面上算；结果只在内存里 |
| 「不滤波强度对齐」 | 同一张图的另一个口径：不按波段重建，$b$ 直接取像素自己的时间序列减均值；仍只产出交流能量与直流两张与 n 无关的图；与全通是两个口径；只累加与谱线根数无关的图，不受累加内存上限约束 |
| 「没有数据的点断开」 | 没图的点不出值，接口不补 0、不插值 |


## 一、存下来的是什么

承诺：一次扫描存两类东西 —— 库里（一条扫描 + 每点一行 + 裁剪矩形 + 手动保存的帧的登记），盘上（每点一张 PNG，名字里带扫描号与序号）。

出什么事会说什么：某点没采到图 → 那一行照写、图就是没有；库里记着、盘上缺 → 取数与导出都当场说清，不静默跳过。

## 二、取数

承诺：给一个像素坐标，返回每个扫描点上的原值与横轴两套读法（读数 / 时间）、两种口径（折算 / 原值）。像素坐标是**保存的 PNG 自己的坐标**，与质心、大图剖面同一套；点在裁剪框外当场报错。

出什么事会说什么：缺读数或缺图的点，那一段就是断的；像素落在画面外是填错了，报错而不是返回一串空值。

## 三、时间与波长两套系数

承诺：时间列 = 位移 × (2 / c)，`1 µm 位移 = 6.6713 fs`；波长刻度用 `λ[µm] = 299.792458 ÷ ν[THz]`。两个系数都只在这一处，随取数响应下发。

出什么事会说什么：响应里没有系数（老接口）→ 前端禁用对应按钮并说清原因，不许自己写一个常数顶上。

## 四、口径（折算 / 原值）

承诺：每条扫描记下「采它的那台设备把位置报成什么单位」，四个数一起下发；改口径只挑一列画，不重取数。系数是 1 或没有记录时，原值那一列不给（拿 µm 冒充原值是编数）。**口径只影响显示**：谱永远按物理时间列（位移 × 2/c）算，两种口径下是同一张谱、频率一根不动；跟着口径换的只有像素曲线与滤波曲线的横轴刻度与范围框。

出什么事会说什么：老数据没有这一列 → 接口说「未记录」，界面可以指认一次，只写「这条是哪台设备采的」这一个字段，读数、图、曲线一个字节都不动。

## 五、裁剪

承诺：一次只裁选中的那一条。预检给出建议框、代表帧上的框、质心范围与离边余量、以及四个数有没有把质心范围框住。动刀时先裁进暂存目录，逐张校验落盘后的那张（尺寸、位深，再按原始坐标取 5 个点与原图逐点相等），整条过了才就地换掉原图；矩形 `x0,y0,w,h` 在库里与 PNG 的 `tEXt`（`CropRect`）各记一份，只在读文件那一层减一次偏移。**两份记录逐个数相等是整幅图读帧的前提**：相位图与强度对齐每读一帧都比一遍（解出来的尺寸对库里那份、PNG 自带的那份矩形对库里那份；只扫 PNG 块头，不解码像素）—— 尺寸相同、原点挪两格的那一种，只比尺寸一点都看不出来，整幅图却会整体错位。取数那条路核的是尺寸。

出什么事会说什么：没有图、正在扫、库和文件对不上（尺寸或矩形，任一份缺、任一份不同都算）→ 当场拒并说清；任何一张不过 → 整条回滚；进程被杀在半路 → 启动时按暂存目录自动收尾。

## 六、导出

承诺：导的是选中的那一条：各点的原始帧（盘上是什么就是什么）＋ 每点元数据 ＋ 一份清单；落在一个独立目录里，可选打成一个 zip（只装不压）；清单是 `manifest.json`，最后一步才写。源文件一个字节都不动。表里**一行一个点、一个都不少**（要的是全部点，不按界面上的默认条数截断）；`points.rows` 是表里实际有几行、`scan.count` 是计划了几个点 —— 中止的、还在跑的那几条本来就采不满，两个数不等不是表缺了行。目标名里的扫描名与批次标记都是外面来的，只当名字用：洗掉不能进文件名的字符，落点必须在导出目录里（跑出去就不导）。

出什么事会说什么：清单最后写、zip 先写 `.part` 再改名；没图的点、库里记着盘上没有的图，都在表与清单里写明 —— 后者**图名照写**（表里是文件名，清单的 `missing_images` 记着它原来那条路径），这样导回来才认得出原样；正在采的那一条照实说「不是完整的一次扫描」。

## 七、导入

承诺：认的是包（目录或 zip），不是某一条扫描；「检查」只读包里的清单与表，本机一个字节都不变（写库要用的值也在这时候解析完 —— 表里有一格不是数，动手之前就拒）；落地次序是**先把扫描号占住**（写一行占号记录，扫描那边的号就发不出它）、再抄进暂存、逐张核对落盘后的图、全过了才改名就位、最后才写点；值一律照抄。占号那一行不是一次扫描：历史表里不列它，启动时由收尾那一档连图带行清掉。

出什么事会说什么：扫描号被占、盘上已有同名图 → 拒，不覆盖、不换号；缺清单、图与表对不上（行数、序号、两行指同一张图、清单说缺而包里却有）、图名带路径 → 一概不收；**中途失败回到原样**：撤掉占的号、删掉这次刚就位的图，盘上不留没人认领的图；库里记着盘上没有的图，导回来照清单里那条原路径写回，往返一次路径不变；本机没量过 `saved_bytes` → 留空，不拿 0 顶。

## 八、相位图

承诺：把一段波段用在每个像素上，一遍扫完全图的帧，算出每个像素的相位与条纹强度两列；结果只在内存里（不落盘、不进库）；缺一个点整条不算并说清是第几个。报出来的「留下谱线」与载波都是**实际参与**的那几根（解不出的已经丢掉）；某一时刻那一张没有公共载波，载波那三格不给数。

出什么事会说什么：波段两端都空（全通）→ 400 拒绝，全通没有载波可比；这一段一根谱线都解不出来 → 400 拒绝并说清，**不交一张全零的图**；扫描进行中 → 允许算，但提醒会跟采图抢磁盘。

**起算那一刻就把手里那一份结果清掉**（相位图与强度对齐同一套机制）：换波段、换扫描号重算时，新的一张还没算完，旧的那一份既不是这条扫描的、也不是这个波段的 —— 留着它，取数那一口会在起算的一瞬间照常交出上一份（旧数组配新的元数据）。「手里这一份」只有一处说了算：算着的时候它是空的，算完才落账，所以「还在算」与「没算过」都是同一个回答。

## 九、强度对齐

承诺：默认是**滤波**口径：把〈滤波曲线〉那段波长用在每个像素上，一遍读盘产出**两张与 n 无关**的图 —— 带内交流能量 $sum_t b^2$ 与直流 $d$（这条扫描该像素所有帧的均值）；$n$ 与直流门限都在界面上算，**改 n 不重读盘、不重算带通**。两张图与相位图同一套坐标口径（原始坐标、裁剪只改读文件那一层）；**结果只在内存里**（不落盘、不进库）。

**不滤波**是同一张图的另一个口径：不按波段重建，$b$ 直接取该像素自己的时间序列减自己的均值 $d$；三步、$n$、门限、灰度、坐标都不变。它答的是「整条时间序列的交流能量」，与**全通**（所有能解出的谱线的交流能量）不是一回事。它只累加三张与谱线根数无关的图（第一帧基准、Σ偏差、Σ偏差²），因此全幅也不受累加上限约束。

出什么事会说什么：缺一个点（没图 / 没记读数）→ 整条不算并说清是第几个；滤波时幅面乘上谱线根数超过累加上限 → 当场拒并说清要多少、上限多少、怎么办（收窄波段或先裁剪），**在分配那几张累加图之前就拒**（没裁剪时幅面由第一帧说了算，那时才知道，但仍在分配之前）；波长填了 0 或负数 → 那是填错了，当场拒（不当成「不限」）；波段一根谱线都没有 → 当场拒并说出谱的格宽与是哪一头卡掉的；全通（两个框都空）**照算**，不当成错误；不滤波与波长同时给 → 400 拒绝并说清「不滤波就不分波段」。

某一根**解不出来**（cos 与 sin 在这串采样上几乎线性相关：条件数超过 $10^{12}$）时，那一根不算 —— 相位图与强度对齐都按"这一段里少一根"处理，与〈滤波曲线〉那边丢的是同一根。判据只看采样的几何、与像素无关；**不是"算错了"，是这几个点定不出这一根**（等间隔奇数点扫描的 Nyquist 那根就是这样：行列式还是正的，条件数却是 $6\times10^{-26}$，系数会被放大到 $10^{11}$）。
