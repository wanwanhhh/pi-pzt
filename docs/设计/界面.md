# 界面设计

**状态**：成形。
**一句话：这份讲屏幕上承诺什么 —— 四页各装什么、每一处能点出什么效果、显示出来的数受什么规矩。** 词在 [词表](../词表.md)；需求在上游（[需求](../需求.md)）；后端给什么见 [扫描](扫描.md) / [相机](相机.md) / [数据](数据.md)。

## 这份设计认领了哪几条需求

| 「界面中文」 | 界面与提示语只有中文 |

## 一、四页与分页

承诺：四页各有各的活；视图名进 URL hash；分页只决定「此刻看哪页」，不决定「能不能做」—— 界面藏起来的东西此刻本来就用不了，但被绕过也不影响设备。

出什么事会说什么：在后端拒绝的操作上点按钮 → 照抄后端的拒绝理由显示，不自己编一句。

## 二、文案按能力声明写

承诺：没有速度指令的设备，速度框禁用并写明原因；停止 / 急停 / 释放的说明按实际能力改写；停止返回软停时，提示语是「软停：不再下发新目标（在途行程拦不住）」；设备掉线时写掉线，不显示上一次的数当实时值。

出什么事会说什么：能力声明里没有的东西，界面上不出现可点的假按钮。

## 三、对准页

承诺：显示当前位置与设备状态；手动点到点、点动、停、释放按能力给；位置曲线取自后端缓冲，写明这一段的点数与平均间隔，标准差按窗口内的实采点算。

出什么事会说什么：曲线范围框没被手填过 → 按这一段数据铺满（X 是 0 ~ 实际跨度，Y 两端各留 5%）；填过就钉住，点「自动范围」松钉；X 与 Y 各钉各的。

## 四、扫描页

承诺：起止、步距、稳定延时、每点采图在界面上设；跑起来看进度；点位表逐行列每点的命令值、读数、间距、偏差、到位、曝光、采图时刻；历史表逐条列过去的扫描，**裁剪与导出的按钮就在这一行上**；导入是独立的一张卡（认的是包）。

出什么事会说什么：扫描中或暂停时点手动操作 → 提示先中止；裁剪不可逆 → 先把预检摆出来（建议框、代表帧红框、质心范围与离边余量），不能裁的原因照抄后端的话；导出前提醒会跟采图抢磁盘。

## 五、预览页

承诺：实时画面 + 质心十字线（十字线按**当前朝向**画在看到的这一帧上，数字仍是传感器坐标）；朝向只转预览；点图给整行与整列两条全长剖面；饱和到顶标出来；图库只列手动保存的帧，改名就真的改名。

出什么事会说什么：相机没接入 / 打开中 / 掉线 → 按后端给的状态写，不给画面；老图缺参数 → 写「未记录」。

承诺：打开「80% 能量圆」时，在看到的这一帧上叠加一个以整幅质心为圆心的圆，并写 D80（像素）；数字来自后端在原始 16 位帧上的窗口内能量，不扣背景、不拟合；背景占窗口总能量 5%～20% 或饱和时，圆照画但标「仅供参考」；超过 20% / 80% 半径贴到窗口边 / 80% 圆出了画面 / 光斑太小时，照抄原因，不画圈、不编直径。**窗口被画面裁掉不算贴边** —— 光斑小又靠边时窗口一定有一边被裁，那只是积分范围到头。关掉、停预览、掉线、切页立即收起。

出什么事会说什么：背景占窗口总能量 5%～20% → 圆照画，说明条写「背景占 xx%，仅供参考」；超过 20%、80% 半径贴到窗口边、80% 圆出画面、光斑太小 → 不画圈、照抄后端原因。

## 六、数据页：取数与曲线

承诺：右栏一次只摆一张图，四种图用一行页签换；切页只改显示 —— 不重算、不重新取数、不重建图（隐藏期间按回退尺寸待着，露出来时按新尺寸排一次）。

承诺：填一个像素坐标（保存的 PNG 自己的坐标）→ 每个扫描点上那一个像素的原值连成曲线；横轴默认取读数（µm），可一键换成时间（fs）；两种读法是同一串数换刻度，切换不重新取数。

承诺：连线默认采图顺序；也可按横轴读数排序，**排过就在图上写明**。

出什么事会说什么：没图的点 → 曲线在那儿断开，不补值；像素落在画面外 → 当场报错，不画空曲线。

## 七、数据页：谱、滤波、包络、极限

承诺：谱按每个点自己那一刻的**物理时间**算（时间 = 位移 × 2/c，非均匀最小二乘，不插值、不假设等间隔），整条扫描参与，一律按采图顺序；**位置口径（折算 µm ↔ 读回原值）不改变这张谱** —— 口径只换像素曲线与滤波曲线横轴的刻度，换了谱不重算、频率一根不动；横轴频率（THz，可切 dB），可切波长（µm，峰高不变）；谱上带相位，画在右边那条轴上：沿频率展开、减掉线性相位、零钉在门限内最强那一根上，门限以下断开；统计条写出「群延迟 τ」与「逐根最大步长」。

承诺：谱那张卡上的「导出这条谱」把这一条**整条**存成一个 CSV：每根谱线一行、频率升序，列是频率（THz）、波长（µm，系数没拿到就没有这一列）、功率（ADU²）、功率（dB）、相位（rad）；文件头用 `#` 行写清是哪条扫描、哪个像素、幅面与裁没裁过、变换点数与真实跨度、频率分辨率与谱线间距、**时间口径**（按物理时间算，与位置轴的口径无关；有读回系数就一并写出）、相位门限与群延迟、波长换算系数与导出时刻。**导的是整条**：可视范围框、纵轴 dB、横轴频率/波长、连线顺序都不参与；相位与图上那条是同一份，**解不出的谱线与门限以下都留空**。

出什么事会说什么：还没有谱（没取数，或这条不合格）→ 不生成文件，提示一句；系数没拿到 → 少这一列、文件头也不写那一行，不自己编一个系数顶上；功率为 0 的地方 dB 留空（不写一个数顶上）—— 图上那条 dB 曲线同样留空（不压一个地板值），自动范围跳过这些空点。

承诺：谱那张卡上的「导入光谱…」把光谱仪导出的谱叠到这张图上 —— 后端认格式（自家 xlsx 或两列 CSV）并减背景（远离主峰的平段取中位数、逐点相减），前端只做两件事：**按峰值对齐**（导入那条乘一个系数，峰落在像素谱的峰高上；切 dB 就是各按各的峰算 0 dB），**落到当前横轴**（频率/波长、功率/dB 都跟着换；导入范围以外留空、曲线断开，不往外延伸）。它是一条对照线：不参与这条谱的计算、不进库、不进「导出这条谱」，换扫描换像素不丢，移除之后这条谱一个数不变。

出什么事会说什么：文件不是谱 / 点太少 / 减完背景没有峰 → 后端原话进提示条；那条线的单位与 ADU² 不是一回事，图例写「导入 <文件名>（已减背景，峰 x µm）」；图下面那行小字写清是哪个文件、哪一列、减了多少背景，以及它不参与计算也不进导出。

承诺：选一段波长 → 只由这段重建的曲线；同图再给包络与相位残差；再给一格强度半高宽（在显示顺序上从峰值向两侧找第一个落到 1/√2 以下的点、两头线性插值，整条算；**宽度是两个交点之差，恒为非负** —— 读数往回走时那一列是降序的，不取绝对值就会报出负宽度）；再给一条可开关的「傅里叶变换极限」。

承诺：谱线密度可切 1/2/4/8 倍 —— 只是同一条谱多采几个点，统计条里「谱线间距」跟着变、「频率分辨率 1/T」不变；换密度不重新取数，滤波曲线、波段、相位图一个数都不变（它们钉在整数格上）。

承诺：某一根谱线在这串采样上**解不出来**（cos 与 sin 在这几个点上几乎线性相关，条件数超过 1e12）时，那一根当它没有 —— 谱上不给功率、不进滤波、不进波段，与后端整幅图丢的是同一根（两边同一份判据，见 [数据](数据.md)）。这不是"出错了"，是这几个采样点定不出这一根。

出什么事会说什么：缺一个点 → 整条不算，说清是第几个；一根谱线都不在框里 → 如实画成 0 平线；波长框填了 0 / 负数 / 不是数 → 当场标红、按填错算（不是「不限」），两张整幅图的起算按钮禁用并写清要填什么，与后端同一句话；系数没拿到 → 波长刻度按钮禁用并说清原因；包络一直不降到阈值以下 → 写「未降到」；相位门限内没有相邻的两根 → 群延迟与逐根最大步长都写「—」，不编一个 0。

## 八、数据页：相位图

承诺：把同一段波长用在每个像素上，画出每个像素跟基准像素差多少相位（弧度）：循环色图 + 图下方色标；同一份结果切「相位差 / 条纹强度」；门限以下的像素涂深灰；坐标一律原始坐标，图上点出来的数直接能填进取数；基准在图上点一下就换，不重取数、不重算。

承诺：「看哪一刻」留空 = 整条扫描；填一个读出位置 → 只算那一刻，统计条写出落在哪一帧（你给的 µm 与那一帧真实记下的读数）；换时刻要重算，换基准、切相位/强度、改门限都不用。统计条里「留下谱线」写的是**实际参与**的那几根（解不出的已经丢掉，不是波段框两端的原值）；「载波」在某一时刻那一张上写「—（某一时刻不取载波）」，不拿一个占位值冒充。

出什么事会说什么：波段两端都空 → 按钮禁用并说清「全通没有载波可比」；两个波长框填错了（0 / 负数 / 不是数）→ 同样算不了，但那句是「哪个框要填什么」，波段那格标红；这一段一根谱线都解不出来 → 照抄后端的拒绝，不画一张全零的图；算的时候先提醒一句会跟采图抢磁盘。

承诺：点图上任意一处定圆心（先切到「圈相位」，否则点图是换基准）、填一个半径，就画出这个圆周上逐点的相位差，横轴是绕行角度（0° 在右边、逆时针为正），纵轴是相位差（弧度）；相位**不折回**，沿绕行方向展开成连续的，绕几圈就画几圈的行程；横轴一格一度，纵轴按这一条自己的数铺满。图上把这个圆与圆心一起画出来。

承诺：统计条写出圆心、半径、绕了几圈、走过的相位、展开时相邻最大步长、取不到几个点；展开最大步长逼近 π 时照实报数，不额外标注也不隐藏。落在图外或强度门限以下的点留空、曲线在那里断开（与图上涂深灰同一件事），不补 0、不插值、不平滑。

出什么事会说什么：没有算过相位图 → 点图不响应，切「圈相位」按钮照样可以切；半径填了非数或小于 1 → 曲线当场收起并说明；整圈都在图外或门限以下 → 统计条写「整圈都在图外或门限以下」并给出怎么办；圆心贴着边点「装满一圈」 → 当场说清整圈放不进去，半径不动。

## 九、数据页：强度对齐

承诺：右栏第五个页签；波段仍只有〈滤波曲线〉那两个框一个来源，两个都空（全通）照算并在统计条写明「全通」；「n」「直流门限 (dB)」「显示上限」三个输入框，改 n、门限与上限**只重画**（后端那两张图与 n 无关），滤波时换波段、换扫描才要重算；n 的下限是 1/2（再小指数为负，直流小的像素反被放大），填了不合法的值就禁用起算并说清为什么；**直流门限按整幅图直流的中位数取**（不是最强像素 —— 直流常有零星热点，按最强算会把整片掐掉），以下的像素涂深灰并计数；图上按**线性**灰度画（最深 = 0、最白 = 色标上限：默认是这张图里最强的那一格，不做对数），图下方色标写出这三格数；「显示上限」一格里可以留空（不掐）、填 99.9%（按分位）、或填一个数（超过的按它画、涂白）；统计条写出 n、直流中位数、门限以下多少像素、超过上限多少像素、幅面与坐标口径 —— 滤波时写留下谱线，不滤波时写口径；鼠标停住读那一格的 S、它的直流与它占最强的百分比，超过上限的照实读真值并注明已涂白。

承诺：卡上有一个「不滤波」勾选。勾上后不按〈滤波曲线〉的波段算，$b$ 直接取每个像素自己的时间序列减均值；公式、n、门限、显示上限、线性灰度、hover 都不变。统计条把「留下谱线」这一格换成「口径」，值写「不滤波（整条时间序列）」，标题写「（不滤波）」；它与「全通」（所有能解出的谱线的交流能量）不是一个口径，不许写「全通」。

出什么事会说什么：波段改过 / 换了一条扫描 → 立刻标出「改过，点重算」，不拿老图冒充；勾选状态与手里那张结果的口径不一致 → 标出「口径改过，点重算」；勾着不滤波时改波段不标「波段改过」（波段不参与）；波长框填了 0 / 负数 / 不是数（滤波口径下）→ 算不了，波段那格标红、起算按钮禁用并写清要填什么；直流门限以下 → 涂灰并计数，不当成 0；显示上限填了认不出的东西 → 按不掐画（色标右端照实写这张图最强的那一格）；扫描进行中照算，但先提醒一句会跟采图抢磁盘。

## 十、一套范围框规矩

承诺：凡有范围框的轴（位置曲线、像素曲线、频率、功率）：输入框是唯一的准，没手填过就自动铺满，填过就钉住；滚轮缩放与按住拖动平移**只改框里的数**；「自动范围」松钉；换读法、换扫描都不让框弹回。

承诺：相位轴（频谱那条、滤波那条）只有自动范围 —— 没有范围框、也不吃滚轮与拖动，按整条画出来的相位自己铺满。

出什么事会说什么：手势监听挂在绘图区上，**换读法重建图之后必须重挂** —— 漏挂的表现为「切过一次读法就失灵」。

## 十一、钉住上面几条的实测

| 事 | 实测 |
| --- | --- |
| 相位轴交给图库自动铺会空掉 | 滚一下滚轮，相位整条消失（滤波那条则是 0~84 变成 10~83） |
| 相位在包络小的地方不可复现 | 加 ±1 灰阶：包络 −1 dB 处抖 0.002 rad、门限线上 0.05 rad、谷底 −57 dB 处 0.84 rad |
| 极限曲线与实测曲线的差 | 峰 49.6 vs 46.7 ADU，逐点差 RMS 4.4 ADU；不对齐相位基准时 RMS 36.7 |
| 排序会藏掉丢帧 | XMT 一条 2000 点、步距 55 nm 的扫描里 318 个间隔往回走，最大 −182 nm |
| 「开关只改显示」要连隐藏的那条一起算范围 | 1.000~1.100 波段：极限峰 57.9，滤波后只有 45.9 ADU |
| 展开的前提（逐根最大步长）真的会踩线 | #98（2000 点、跨度 667 fs）：4× 密度 1.399 rad 可用；1× 密度 3.100 rad ≈ π，同一段相位展开到 −8.9~10.9 rad，已不可信 |
| 减线性相位之后最强那一根附近确实是平的 | 同一份谱、−10 dB 门限：残余相位 −0.126~0.253 rad（减之前是几弧度的斜坡），群延迟 τ = 304.7 fs |
