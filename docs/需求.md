# 需求

**状态**：成形。
**一句话**：这个项目要做到什么 —— 判断「做没做到」的依据，也是砍掉多余设计的依据。
**怎么读**：目标与非目标各分两栏 —— 落在屏幕上的归「界面」，其余归「后端」。优先级：**必须**＝做不到就是没做完；**应该**＝可以晚一步，但要有；**可选**＝有余力才做。「」里的是**条目名**，别处引用一字不改。
**不在这份里**：怎么做（选型、分层、代码组织）见 [../AGENTS.md](../AGENTS.md)；给到什么效果见 [设计/](设计/)；设备事实与实测数字见各设备的「认识账」；写法见 [文档编写规范.md](文档编写规范.md)。

## 目标 · 界面

### 一、四页各管一件事

- **「四个页面」（必须）。** 对准（位置读数 / 手动控制 / 位置曲线）、扫描（参数与进度 / 点位 / 历史）、预览（相机画面 / 手动保存的图库）、数据（对的是盘上的数据，不是设备）四页都在，一页只装一件事。
- **「数据页不参与互斥」（必须）。** 数据页只读盘上的东西、不碰设备、不排队进设备线程：扫描跑着也能翻旧数据，扫描也不等它。
- **「视图名进 URL hash」（应该）。** 刷新、开两个标签各停一页，都能回到原来那一页。
- **「分页只是显示」（必须）。** 分页不承担防误操作：任何一页被绕过或篡改，设备行为都不变 —— 真正的拒绝永远来自后端。
- **「界面中文」（必须）。** 不需要登录，单人单机用。

### 二、屏幕上的话按实情说

- **「能力声明改文案」（必须）。** 设备能力随状态下发，界面据此禁用按钮、改写说明；能力声明本身不参与夹取与安全判断。
- **「做不到的动作说清楚」（必须）。** 设备没有的能力（改速度、停止运动、关伺服、自动重连）在界面上禁用并写明原因，不假装接受。
- **「软停要说明白」（必须）。** 软停时提示语写明「软停：不再下发新目标（在途行程拦不住）」。
- **「界面上每个数说得出从哪来」（必须）。** 读数是谁报的、什么单位；没有记录的地方写「未记录」，不猜、不倒填。
- **「加工过的显示要写明」（必须）。** 排序、裁剪、换刻度这类加工，界面上要写出来（例：曲线按横轴读数排过序，就要标出来）。
- **「设备不可用时不冒充」（必须）。** 掉线后不拿上一帧冒充实时画面，也不拿上一次的读数冒充当前位置。

### 三、对准页

- **「手动控制」（必须）。** 界面上能点到点移动、能停、能释放；能力不同的设备按实情给按钮与文案。
- **「位置曲线」（必须）。** 看得到最近一段的读数与抖动，并写明这一段的点数与平均间隔。
- **「位置曲线的范围可填」（应该）。** X 与 Y 各钉各的 —— 填了 Y 不该把 X 一起钉住；「自动范围」一键松钉。

### 四、扫描页

- **「参数在界面上设」（必须）。** 起止位置、步距、稳定延时、每点是否采图都在界面上设定，跑起来看得到进度。
- **「点位表」（必须）。** 每点的命令值、采图那一刻的读数、设备原值、稳定延时、到位与否、曝光、采图时刻、图的尺寸与位深都看得到。
- **「历史扫描表」（必须）。** 过去每一条扫描都在表里；**裁剪与导出的入口就在这一条上**，点的永远是那一条（不是同名整组）。
- **「扫描能暂停、继续、中止」（必须）。** 三个动作各自独立。

### 五、预览页

- **「实时画面」（必须）。** 相机接上就能看连续画面；曝光随时可改，不用停预览。
- **「质心十字线」（必须）。** 画面上标出亮心：口径是整幅强度加权重心（不扣背景、不设阈值、不开窗），坐标永远按传感器坐标说，换了预览朝向也不换算。
- **「朝向只转预览」（必须）。** 0/90/180/270 只改看到的画面；保存下来的原生帧永远是传感器朝向。
- **「预览上点图看剖面」（必须）。** 点一下给出过该点的整行与整列两条全长剖面，原值上图（不平滑、不扣背景、不归一化、不算峰位与半高宽）；坐标按当前朝向那一帧算，实时刷新。
- **「饱和要标出来」（应该）。** 峰值到顶时在界面上标出来（按实测满量程判）。
- **「80% 能量圆」（可选）。** 预览页开关打开时，在原始 16 位帧上以整幅质心为圆心，在光斑附近窗口内累积原始强度，画出包含 80% 能量的圆并写出直径（像素）；不扣背景、不做拟合与平滑；只显示，不改图、不入库、不进导出物；按背景很弱的口径，背景占窗口总能量 5%～20% 时照画但标「仅供参考」，超过 20%、圆贴到窗口边或画面边、信号太弱时不给数并说明原因。
- **「图库」（必须）。** 只列手动保存的帧（按登记表，不靠文件名猜）；改名就是真改磁盘文件名。

### 六、数据页

- **「一次只摆一张图」（必须）。** 像素曲线 / 频谱 / 滤波曲线 / 相位图用一行的页签换；切页只改显示 —— 不重算、不重新取数、不重建图。
- **「像素取原值」（必须）。** 填一个像素坐标（保存的 PNG 自己的坐标），取每个扫描点上那一个像素的原值：不平滑、不扣背景、不归一化。
- **「横轴默认是读数」（必须）。** 默认横轴是采图那一刻记下来的读出位置（µm），不是命令值、也不是点序号。
- **「横轴可换时间」（必须）。** 一键把横轴换成时间（fs）：光在干涉仪里往返一趟，光程差 = 2×位移，再除以 c（1 µm 位移 = 6.6713 fs）；两种读法是同一串数换刻度，切换不重新取数；系数只写在后端一处。
- **「横轴范围可填」（必须）。** 两个输入框是唯一的准；没手填过就按这一段数据两端各留 5% 铺满；滚轮缩放与拖动平移只改框里的数（改完即钉住）；「自动范围」复位；不设缩放下界。
- **「连线顺序可选」（必须）。** 默认采图顺序；也可按横轴读数排序 —— 排序只是一次置换，不产生新数、不改统计，**排过必须在界面上写明**。
- **「没图的点断开」（必须）。** 曲线在那儿断开，不补值、不插值；点落在画面外是坐标填错了，当场报错，不返回一串空值。
- **「频谱」（必须）。** 横轴频率（THz）、纵轴功率谱（可切 dB，0 dB = 最强那根）：按每个点自己那一刻的时间算（真实点间距、非均匀最小二乘，不插值、不假设等间隔）；整条扫描的全部点参与（可视范围框只管看）；一律按采图顺序算；缺一个点（没图 / 没记读数）整条不算，当场说清是第几个；频率格 = k/T（T 是真实首末跨度），上限卡在名义 Nyquist；已去均值、不加窗；功率 = (A²+B²)/2。
- **「谱线可加密」（应该）。** 谱线密度可选 1/2/4/8 倍（默认 4 倍）：频率格从 1/T 缩到 1/(密度×T)，同一条谱多采几个点。**这不是提高分辨率** —— 分辨率永远是 1/T，界面上「谱线间距」与「频率分辨率 1/T」两格分开写；也不是补零（非均匀采样没有"零该插在哪一刻"，补零要先重采样）。整数格上的功率一根不变，滤波、波段、相位图都不跟着变；换密度不重新取数。
- **「频率轴可切波长」（应该）。** 在 THz 与 µm 之间切：每根谱线的功率一根不变，只换横坐标（不做密度换算）；钉住的范围框按同一个式子换算过去（两端对调）；系数没拿到就禁用并说清原因，不许自己写一个常数顶上。
- **「频率与功率的范围可填」（应该）。** 两个轴各有范围框 + 「自动范围」；频率轴另有「聚焦最强峰」：把窗口填成最强那根附近（宽度 = 峰频的 20%，太窄时至少 20 根谱线宽），它只是替人把两个数填进范围框并钉住。
- **「谱上带相位」（应该）。** 每根谱线相对这条序列里最早那一拍的相位，画在同一张图右边那条轴上：单位弧度；先沿频率升序逐根展开（相邻两根的相位差折到 (−π, π] 再累加）；再减掉线性相位（整段信号晚到的那条斜坡），零钉在门限内最强的那一根上 —— 于是最强那根处恒为 0、它附近几乎是平的，剩下的起伏就是色散；统计条写出被减掉那条直线的「群延迟 τ (fs)」与「逐根最大步长 (rad)」（展开的前提要 < π；量不到就写「—」，不编数）。「相位门限 (dB)」以下的不画（留空、断开，不补值不插值），展开与减线性相位也不从它们身上过；留空 = 不设门限。右边这条轴只有自动范围，按整条画出来的相位铺满。
- **「导出频谱」（应该）。** 那条像素的整条谱能存成一个表格拿出去：每根谱线一行（频率、波长、功率、相位），文件里写清是哪条扫描、哪个像素、怎么算出来的（点数、真实跨度、分辨率与谱线间距、口径、相位门限与群延迟）；导的永远是整条（不受可视范围、纵轴 dB、频率/波长读法影响）；相位与屏幕上是同一份，门限以下留空、不补 0；这条谱不合格（缺一个点、点太少）就不生成文件。
- **「按波长选一段」（必须）。** 只留下落在框里的那几根谱线，按每个点自己那一刻的时间加回时域，得到「只由这段构成」的曲线：不插值、不重采样；两个波长框空着 = 全通，只填一边另一边不限；一根都没留下就如实画成 0 平线；直流（均值）不加回来；边界硬截断。换波段、换横轴读法、换连线顺序都不重新取数、也不重算谱。
- **「包络与相位残差」（应该）。** 同一张图上再给两条：包络（左轴）与相位残差（右边那条轴），一次累加同时给出三样；相位要沿采图顺序逐点展开、减掉带内功率重心那条线性相位（以第一个采样点为 0）；门限按包络（相对最强，默认 −20 dB，留空 = 不设门限），门限以下断开；统计条里要写出「逐点最大步长 (rad)」自证展开，全通时它逼近 π，那段相位别看。
- **「强度半高宽」（应该）。** 包络给一格强度半高宽：强度降到一半 ⇔ 包络降到峰值的 1/√2；在显示顺序上从峰值向两侧找第一个落到阈值以下的点、两头线性插值；整条算（不吃可视范围框）、与相位门限无关；跟着横轴读法走；任一侧一直不降到阈值以下就写「未降到」，不编一个数。
- **「傅里叶变换极限」（可选）。** 同一段谱线、幅度一根不动，只把每根的相位拉平到同一个基准（离包络的时间重心最近的那一拍），画出「这条带一点色散都没有时该长什么样」；可开关，**开关只改显示**；一根谱线的波段上必须与实测曲线逐点重合。
- **「位置轴可切口径」（应该）。** 在折算 µm 与设备读回原值之间切：口径是设备属性、系数只写在后端一处，后端四列一起下发，前端只挑一列画；切换不重新取数，钉住的范围框按系数换算；口径记在扫描上；老数据可以在界面上指认一次（只写「这条是哪台设备采的」，各点读数、图、曲线一个字节都不动）；系数是 1 时同样禁用并说明；不许猜系数。
- **「相位图」（应该）。** 把同一段波长用在每个像素上，画出每个像素跟基准像素差多少相位（弧度）：循环色图 + 图下方一条色标，两端 −π 与 +π 落在同一个颜色上（绕圈处接得上）；同一份结果能切「相位差 / 条纹强度」，不重算；强度门限以下的像素涂深灰（那里是「算得出却不可复现」，不是当成 0）；坐标一律原始坐标，图上点出来的坐标直接能填进取数；基准在图上点一下就换、只决定零在哪（不重取数、不重算）；波段只有〈滤波曲线〉那张卡一个来源，两个框都空就拒绝（全通没有载波可比）；结果只在内存里，不落盘、不进库；v1 不做空间解包裹、不做 nm 换算。
- **「强度对齐绘图」（应该）。** 把同一段波长用在每个像素上，得到一幅图：每个像素先减去它自己的直流（这条扫描该像素所有帧的均值），再除以该直流的 (2n−1)/(2n) 次方（n 由界面上填，默认 3），最后把得到的信号做**平方积分**（逐点平方再求和，**不除以点数**）；像素自己的直流就是「对齐」的那个分母，亮暗与照明不均因此被除掉；波段只有〈滤波曲线〉那张卡一个来源，**两个框都空（全通）也不因为"没有载波"被拒**（这里不需要载波；算不算得下另看内存，见下）；改 n 只重画，不重读盘、不重算；直流低于「直流门限 (dB)」的像素不画（涂灰并计数，留空 = 不掐），门限相对**整幅图直流的中位数**；累加内存超过上限时当场拒并说清要多少、怎么办（收窄波段或先裁剪），不跑到一半才爆；图上按**线性**灰度显示（不做对数）；坐标一律原始坐标；结果只在内存里，不落盘、不进库。
- **「不滤波强度对齐」（应该）。** 强度对齐可以勾选「不滤波」：不做带通，每个像素的 b 直接取它自己的时间序列减均值；后面的三步、n、门限、线性灰度、坐标口径都与「强度对齐绘图」相同。不滤波与「全通」是两个口径（全通 = 所有能解出的谱线的交流能量），界面上不许混写；不滤波不受「带内谱线根数 × 幅面」那条累加内存上限限制。
- **「圈相位」（应该）。** 在相位图上点一个圆心、给一个半径，沿这个圆周逐点取每个像素跟基准像素差多少相位，画成一条按绕行角度铺开的曲线；相位**不必折回**（连续性由展开给出，绕几圈就画几圈的行程），展开的前提照实报出来；图外与强度门限以下的点留空、曲线断开并计数；换圆心、换半径只重画（不重算相位图、不重读盘）；同一份相位图只做这一件事，不做环上的平均或拟合。

- **「相位图看哪一刻」（应该）。** 相位图能选「整条扫描」或「某一时刻」：后者按读出位置（µm）指定，画出扫描走到那一处时每个像素的相位；落在哪一帧上照实写出（你给的 µm 与那一帧真实记下的读数）；只有一根谱线的波段上两种口径结果相同，要照实说明而不是留一个看不出差别的开关；换时刻要重算，换基准、切相位/强度、改门限都不用。
- **「裁剪」（必须）。** 一次只裁选中的那一条扫描，它的每一帧都裁成同一块、就地换掉原图（文件名不变）；裁过的还能再裁，但只能越裁越小、只能在现在那块地里挑；动手前先摆预检（建议框、代表帧红框、质心范围与离边余量），不能裁的原因当场拒掉并说清；扫描进行中一律拒绝；图库里手动保存的帧不裁；坐标口径不因裁剪改变（曲线、剖面、图上点出来的坐标一律还是原始坐标）；质心只搬不重算；「这台机器上省了多少字节」是累加的，没量过就留空、不拿 0 顶；原图在全部校验通过之前一个字节都不动，不存在「一半裁了一半没裁」；进程被杀在半路，启动时自动收尾。
- **「导出原始数据」（必须）。** 入口在历史扫描表那一条上，导的是那一条；把各点的原始帧连同每点元数据抄一份出去，另加一份清单；是抄一份出去，不是搬出去 —— 源文件一个字节都不动；图和表一律原样（不解码、不裁剪、不重算、不补值）；没图的点、库里记着盘上没有的图，都要写明；可选打包成一个 zip，只装不压；导到一半不算导完。扫描跑着也能导，但先提醒一句会跟采图抢磁盘。
- **「导入原始数据」（必须）。** 入口在历史扫描卡片上（认的是包，不是某一条扫描）；扫描号沿用包里那个，本机已经占了、或盘上已有同名图就拒，不覆盖、不换号；「检查」那一步只读包里的清单与那张表，本机一个字节都不变；落地次序是先抄进暂存、逐张核对落盘后的图、全过了才改名就位、最后才写库；值一律照抄；只认导完了的包（没有清单的不收）；源包一个字节都不动。

### 七、不可逆的事先说清后果

- **「不可逆的事先说清后果」（必须）。** 会造成不可恢复后果的操作（裁掉原图、删数据），动手前把「会发生什么、能不能撤销」摆在使用者面前。

## 目标 · 后端

### 一、工具与它服务的人

- **「单人单机、只监听本机」（必须）。** 一人一机本机用：不登录、不多人同时操作，只听 127.0.0.1。
- **「闭环控制台」（必须）。** 一台位移台加一台相机的闭环控制台：逐点走位、每点采一张图、事后按像素取数，看信号随位置怎么变。
- **「一次扫描 = 逐点移动 + 每点一张图」（必须）。** 按命令值逐点移动，每点采一张图。
- **「位置只记一点」（必须）。** 位置只在每个扫描点采一次、随该点入库；点与点之间的运动过程（怎么走到位、有没有过冲、整定多久）本程序看不到，也不做这类分析。
- **「任务独立于浏览器」（应该）。** 扫描由后端执行器跑，关页面、断网都继续。

### 二、权威只有一处

- **「后端负责控制」（必须）。** 硬件访问、参数校验、限位、安全逻辑、状态机全在后端；前端只负责显示与输入。
- **「拒绝永远在后端」（必须）。** 前端被绕过或篡改都不影响设备安全。
- **「前端不维护意图」（必须）。** 界面不自己记「用户想要什么」，按后端给的状态显示。
- **「进硬件前必校验」（必须）。** 参数校验、软限位夹取、设备错误码检查必须保留。

### 三、人随时能停下

- **「随时能停」（必须）。** 正在做的事随时能停，不必等它跑完。
- **「停止与释放分开」（必须）。** 两个动作不合并；各自能做到什么程度按设备的实话说明。
- **「一台设备一个使用者」（必须）。** 扫描占着设备时，手动操作与相机接口被明确拒绝（409），不是靠界面上把按钮藏起来。
- **「停完说得清状态」（必须）。** 停下之后能说清停在哪儿、这次扫描算中止还是失败。

### 四、扫描的口径

- **「单向逼近」（必须）。** 扫描时每个点都从同一侧走过去（往返走会因方向性迟滞让图像错位）。
- **「位置精度是台子的属性」（必须）。** 后端只保证「命令了什么」，保证不了「实际走了多少」；「等间隔」是按命令值和读数说的，不是按真值说的。
- **「到位由设备层给结论」（必须）。** 上层只处理「到位 / 超时 / 中止」，不关心底层怎么判。
- **「PI 每点按步距复核」（必须）。** 采图前再校验一次偏差，超过半个步距就判该点无效：不采图、不入库、中止扫描。
- **「XMT 不做任何到位判据」（必须）。** 不读回确认、不按步距复核、超差一概不拦、不中止、不标无效；等满稳定延时就直接采图。
- **「等待时长不是设备常量」（必须）。** 改了设备的整定就得重设等待时长；等多久由使用者负责，后端不兜。
- **「读数与闭环同一个传感器」（必须）。** 两者自洽，所以「到位」判据可靠；传感器自身的标定误差要靠外部标定，不在本仓库范围内。
- **「只做闭环」（必须）。** 不提供开环 / 电压模式。
- **「不需要高实时采样」（必须）。** 慢速轮询足够，不做 10 kHz 高速采集通路。
- **「预留联动接口」（应该）。** 每点到位后有位置给外部设备调用，图像路径写回该点元数据。
- **「位置曲线不额外轮询设备」（必须）。** 曲线取自遥测轮询的环形缓冲；扫描进行中改用扫描器刚读到的那次位置，一拍设备都不多花。

### 五、设备层共同要求

- **「行程以实测可用区间为准」（必须）。** 设备自报的限位采不采信按设备文档定：没有标定数据的设备只能当参考区间。
- **「折算系数不能长期写死」（必须）。** 系数被改过要看得出来（现在只剩「读数落不到目标附近」与界面的「到位」列）；连接时不动台子。
- **「每台设备按自己的事实实现」（必须）。** 停止 / 释放 / 行程 / 停稳按各自文档如实实现，不拿另一台设备的结论顶上。
- **「设备能力随状态下发」（必须）。** 能力声明只影响文案与可用性，绝不参与夹取与安全逻辑。

### 六、PI

- **「PI 停稳由控制器判」（必须）。** 到位信号 + 一段固定延时（延时可调）。
- **「PI 扫描必须单向逼近」（必须）。** 细节与数字见 [pi/设备认识账.xml](pi/设备认识账.xml)。
- **「PI 的停止与释放按设备语义」（必须）。** 不许一律写成「保持伺服」。

### 七、XMT

- **「XMT 仅 Windows」（必须）。** 不做 Linux 分支。
- **「XMT 在设备边界折算」（必须）。** 读回值与设点单位不同，绝不让读回值流进设点。
- **「XMT 无速度指令」（必须）。** 明确拒绝并报错，不假装接受；界面速度框禁用。
- **「XMT 没有停止运动与关伺服」（必须）。** 这两个动作按设备文档能做的表达，界面文案说实话。
- **「XMT 丢帧是静默的」（必须）。** 丢帧不会被当场发现，会照常采一张错位的图、扫描仍报完成；能事后看的只有每点入库的读出位置。

### 八、相机

- **「相机仅 Windows」（必须）。** 走厂家 Python SDK，不做别的路径。
- **「曝光与增益」（必须）。** 曝光由预览与采图共用同一个值、随时可改（预览流不用停）；增益恒为 0，改增益的接口一律拒绝。
- **「保存的帧是原生数据」（必须）。** 手动保存的帧 = 原生全幅、16 位灰度、不裁剪、不拉伸、不伪彩。
- **「图自己带着参数与亮心」（必须）。** 曝光与质心写进 PNG 自己的 tEXt 块；老图没有就写「未记录」，不许猜。
- **「一台相机一套设置、一条流」（必须）。** 原生全幅 ROI + 同一个曝光 + 增益 0，会话出生时写一次并读回；预览、手动保存、扫描共用；一个会话最多 arm 一次。
- **「每点采图的顺序」（必须）。** 触发 → 读位置 → 取帧（串行做就是白等一次曝光）。
- **「掉线只能手动重开」（必须）。** 重开 = 重建整个相机会话；不做自动重连。
- **「相机状态由后端派生」（必须）。** 未接入 / 空闲 / 正在打开 / 预览中 / 归扫描用 / 掉线待重开；没有会话就没有帧。
- **「相机与位移台互斥」（必须）。** 扫描进行中相机接口一律 409；开始扫描前后端自己先关预览。
- **「扫描中相机出错即整条失败」（必须）。** 不重试、不「该点判无效后继续」、不自动清理半截扫描；半截扫描由人在界面上手动删除。

### 九、数据宁可没有，也不能是假的

- **「没有数据的点断开」（必须）。** 不插值、不补值。
- **「坐标口径不因加工改变」（必须）。** 裁过的和没裁过的可以混着比。
- **「不留半成品」（必须）。** 加工不成功就整条回滚，原数据要么完好、要么明确回到原样。
- **「数据要能离开这个程序活着」（必须）。** 图是通用格式、自己说得清用了哪次参数与亮心在哪、原始文件拿得到。
- **「导出物自己说得清」（必须）。** 是哪条扫描、每点的命令值与实际读数、图的尺寸与口径（裁没裁过）、缺什么也写明；不假装完整。
- **「搬出去能原样搬回来」（必须）。** 换机器、换硬盘之后照旧：取出来的数、画出的曲线与搬走之前一样，认得出是同一条扫描；搬回来不动包本身、也不动本机已有的数据，撞上就停。

### 十、跨平台

- **「Linux 与 Windows 都能跑」（必须）。** 各设备自身的平台限制如实说明。

## 非目标 · 界面

- 不在前端复制业务逻辑、不做本地权威状态、不自己判断限位。
- 不做图像加工：平滑、扣背景、归一化都不算。
- 相位图 v1 不做空间解包裹，也不做 nm 换算。

## 非目标 · 后端

- 不做多用户、权限、远程访问（只监听本机）。
- 不做开环与电压模式。
- 不替设备承诺绝对精度（外部标定不在本范围内）。
- 不做连续高速位置记录，也不做频响、阶跃响应这类分析。
- 不自动重试、不自动清理：掉线手动重开，半截任务由人处理。
- 不做相机自动重连。
- 不替用户假设光路（不做 nm 换算要用的反射 / 双程假设）。
